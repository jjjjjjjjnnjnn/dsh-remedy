## dsh-remedy 0.4.18

### Added

- **P-0052 — a completed turn that ends on the tool call the UI does not read is now
  counted.** Upstream #12741 reports a long tool loop that finishes with tool rows and no
  sentence. The host can end a turn `completed` on a step that still carries a tool call
  when a tool result marks the turn concluded, while the client accepts a final step only
  when it has visible content and no tool-call block. A local probe reproduced the shape:
  the last step is a text block and a tool call, and the turn ends `completed`; the
  control, same endpoint and prompt with the concluding call off, takes a second
  text-only step. `scan` now reports `completed_on_tool_call` beside
  `completed_without_answer`, and `explain` prints one `TOOLCALL` finding and exits 1 when
  the count is positive. P-0044's answer rule is unchanged: a tool call is still visible
  work; this is a second, narrower count.

### Changed

- `scan` also reports `completed_on_tool_call`, and `explain` names it as a `TOOLCALL`
  finding; the existing answer rule is unchanged.

### Fixed

- **The first screens quote the suite they are on.** The two READMEs still said "the
  suite is 399 tests" while the fact pack said 0.4.17 ships 405; the number is bound to
  the release and a governance rule reads it against the pack.
- **The handoff no longer repeats an older round's byte account.** The status table is
  the single home, and a rule rejects an expired byte pair in live prose.
- **The patch docs' reproduction steps run from the repository.** Thirteen sections
  cited paths under `.tmp/`; they now name shipped commands, and a rule rejects a
  `.tmp/` path or a cited path that does not exist.

### Package size

- `dsh-remedy@0.4.18`: 38394 bytes compressed, 38 files, 125711 bytes unpacked.
- `dsh-remedy-core@0.4.18`: 40796 bytes compressed, 29 files, 132371 bytes unpacked.
