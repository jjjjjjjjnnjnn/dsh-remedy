# P-0010 — The npm page documented a CLI that had not existed since 0.3.3

**Status**: `tested`  **Severity**: minor  **Surface**: `cli`  **Depends on**: P-0004

## Symptom

Two strings described `scan`, and both were wrong in the same way:

```
packages/plugin/README.md : dsh-remedy scan    <session.jsonl> [--json] [--out <file>]
packages/plugin/src/cli-args.ts (USAGE) : dsh-remedy scan <session.jsonl|session.v4.jsonl.zstd> [--json] [--out <file>]
```

Both omit the directory form, `--since` and `--max-files`, all of which P-0004
shipped in 0.3.3:

```
$ node packages/plugin/dist/cli.js scan "C:/Users/rongj/.dsh/sessions" --since 2026-11-11T00:00:00Z
files=78
attempts=68 fused_calls=0 fusion_failures=0 repairable=0 unreadable_lines=0
turns=13 completed=5 max_tokens=2 aborted=3 error=3
  error codes: UNSUPPORTED_REASONING_EFFORT=3
before_since=156209
```

A directory is accepted, `--since` is applied and its drops are counted, and
`--max-files` caps the walk (`packages/plugin/src/scan-command.ts:60-69`). The
documentation was two releases behind the binary.

The first line is also the page npm renders for the package, so this is not an
internal comment: the public install page described a tool that cannot take the
argument most users would pass it.

## Why it lasted

Nothing looked at either string:

- `scripts/gate_copy.mjs` covers the eleven outward files at the repository root.
  `packages/plugin/README.md` is not one of them.
- `docs/copy` never generated it: it is hand-written package prose, which is why
  it drifted while the generated files stayed current.
- `tests/governance/public-copy.test.ts` iterates the same eleven-file list.
- No test executed `--help` or compared the two strings, so a red gate was
  impossible by construction. This is the third defect of the same family as
  P-0004 and P-0006: a fact that no mechanism watches is a fact that rots, and
  this one rotted on the page strangers read first.

## What changed

1. `packages/plugin/src/cli-args.ts` — `USAGE.search` now reads
   `dsh-remedy scan <session.jsonl|directory> [--since <iso>] [--max-files <n>] [--json] [--out <file>]`.
   The four per-command descriptions were also condensed from two lines to one,
   which is what pays for the flag list under a byte ceiling with three bytes of
   headroom: the emitted `cli-args.js` went from 3086 to 2972 bytes and the
   plugin total from 67997 to 67883.
2. `packages/plugin/README.md` — the `## CLI` block now carries the identical
   line, plus three sentences that state the directory form, `--since` accounting
   and `--max-files`, and that `repair` reads stdin / a `.json` fixture through
   `arguments`.
3. `tests/unit/cli-usage.test.ts` (new) — two tests: the packaged README's
   `scan` line must equal the `USAGE` `scan` line after whitespace normalisation,
   must name `--since`, `--max-files`, `--json` and `--out`, and must admit a
   directory; and the old one-file-only shape must not reappear. Both fail
   against the pre-patch strings (the README line and the `USAGE` line differed)
   and pass against the pair that now exists.

## What this does not fix

- The gate set still does not cover `packages/*/README.md`. The new test is the
  only mechanism, so it guards the two strings it compares, not the package
  README as a whole.
- `gate_copy` still cannot see this file, because it is not generated by the
  copy channel and has no `output_sha256`. Moving it into the channel is a
  separate decision: it would then be generated from the fact pack instead of
  being hand-written.
- The condensing that paid for the flags shortened prose that explained behavior
  (`status` lost the sentence about `--journal` printing the last counters). It
  is now one line per command; the detail lives in the fact pack and this
  document.
- No live artifact is possible: the CLI usage text is not a resident seam, so the
  patch stays `tested`.

## Reproduction

```
git show HEAD:packages/plugin/README.md | grep 'dsh-remedy scan'
git show HEAD:packages/plugin/src/cli-args.ts | grep 'dsh-remedy scan'
node --test tests/unit/cli-usage.test.ts        # red before, green after
node packages/plugin/dist/cli.js --help | grep scan
node scripts/gate_size.mjs                      # 67883 of 68000
```
