## dsh-remedy 0.4.8

### Fixed

- **A tool call with no identity no longer poisons the session.** The adapter can end a stream with a block whose id and name are both empty (upstream discussion #13211). The plugin used to count the refusal and pass the block through, so the host wrote `tool/call` with an empty `callId` and the V4 log refused to resume the session on the matching result. The block is now rewritten in place: a traceable `call_remedy_N` id when the id is empty, and `remedy_unattributed` when the name is empty. The runtime answers `UNKNOWN_TOOL`, the turn continues, and the session stays resumable.
- Measured on an isolated harness, with and without the plugin: without it the turn exits 1 with `format v4 tool/result at seq 18 requires toolCallId matching its tool source`; with it the assistant message carries `call_remedy_1 / remedy_unattributed`, the result cites that id, and the same session completes a second turn. The artifact is `data/results/live-empty-call-2026-11-14T16-02-00.000Z.json`.

### Added

- A live probe for the empty-identity case: `scripts/record_empty_call_probe.mjs` runs an isolated `DSH_HOME` against a local OpenAI-compatible endpoint, with and without the plugin, and records both sessions, the journal and the resumed turn in one artifact.

### Changed

- **The ledger stopped carrying the long form of every patch.** Each registry record repeated its patch document; the registry had 1697 bytes left against a record of 2107-2377 bytes. Eight of the longest records now keep one sentence per field and short limits, with the narrative staying in `docs/patches/`. `registry.js` fell from 66303 to 61509 bytes before the two new records, and the 68000-byte cap did not move.
- Splitting the registry by seam was measured and rejected for payment: it moves the same bytes into other modules and still spends the same budget.

- `dsh-remedy-core@0.4.8`: 39869 bytes compressed, 23 files, 128145 bytes unpacked (98824 of `dist/*.js`), shasum `2567629d…`.

### Notes

- This release carries 33 patches: 4 `verified` and 29 `tested`.
- Byte budget: residency 41510 of 44000, CLI 41362 of 42000, total 82872 of 83000 (128 bytes of headroom); engine 98824 of 104000, `registry.js` 64937 of 68000. No cap moved. Both unpacked totals are smaller than 0.4.7 even though two patches were added: one de-duplicated the ledger, the other paid its bytes by condensing comments.
- The adapter that can emit an incomplete call is still not fixed; the plugin keeps the session usable and names what it refused. A call whose arguments parse to a non-object value is untouched.
- Measured on DSH 0.2.2-rc.3 (Windows). The supported range is unchanged.
