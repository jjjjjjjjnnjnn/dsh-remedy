## dsh-remedy 0.3.7

### Added

- P-0010: The packaged `README.md` (the page npm renders) documented `scan` as `<session.jsonl> [--json] [--out <file>]` and the CLI usage output said `<session.jsonl|session.v4.jsonl.zstd>`, while the binary has accepted a directory, `--since` and `--max-files` since 0.3.3. Both strings now carry the identical line: `<session.jsonl|directory> [--since <iso>] [--max-files <n>] [--json] [--out <file>]`.
- `tests/unit/cli-usage.test.ts` fails if the two usage strings ever diverge again or if the one-file-only shape returns.

### Changed

- The four per-command descriptions in CLI usage were condensed to one line each so the longer flag list paid for itself under an unchanged 68000 byte ceiling. Emitted `cli-args.js` fell from 3086 to 2972 bytes, and total emitted plugin code fell from 67997 to 67883 bytes.

### Fixed

- The `scan` documentation on the package `README.md` and CLI usage no longer describes a CLI that has not existed since 0.3.3, on the page strangers read first.
