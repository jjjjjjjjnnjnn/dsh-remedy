## dsh-remedy 0.4.3

### Added

- `scripts/record_adaptation.mjs`: one recorder for "which runtime did this plugin actually run on". It reads an isolated `DSH_HOME` (the runtime's own `runtime.json`, the installed plugin version, the journal, the session logs) and writes `data/results/adaptation-<plugin>-on-<runtime>-<stamp>.json` with hashes, so the next upgrade is measured instead of argued from a version number.

### Changed

- Re-measured on **DSH 0.2.2-rc.3**, the desktop build released today. All three seams are declared identically in 0.2.2-rc.1 and 0.2.2-rc.3 — `llm/stream` stays a synchronous waterfall over `AsyncIterable<StreamChunk>`, `agent/pre-step` keeps `PreStepDecision`, `agent/request-error` keeps `RequestErrorAction` — so the supported range stays `>=0.2.0-rc.1 <0.3.0-0`, and only the sentence that says what was measured moved: `0.2.2-rc.3`, with the artifact beside it.
- One measured behaviour changed: on rc.1 the adapter never closed a tool-call block, which is why the finish-time rescue is the primary path; on rc.3 it closes the first fragment itself and leaves the surplus object to that same rescue. Both sequences are accepted, and P-0002's record now says which version showed which.

### Fixed

- The published page and the fact pack no longer say the plugin was measured on 0.2.2-rc.1 while the runtime in use is rc.3.

### Notes

- No seam behaviour changed: the engine, the wrapper and the CLI are byte-identical to 0.4.2 apart from that registry text.
- This release exists because the probe that checked the upgrade found a boundary the record claimed was closed. A fused text that glues two calls of **different** tools carries one name for that index, so fragments after the first inherit it: measured twice on rc.3, the synthesized call was dispatched as `read` with shell arguments and the tool answered `INVALID_ARGS`. Visible, not silent, but a wrong dispatch — recorded as blind spot `BS-18`, with the fix planned as `P-0027`.
- The byte budget did not move: residency 41143 of 44000 bytes, CLI 41362 of 42000, total 82505 of 83000.
- A cold directory installed `dsh-remedy@0.4.3` from the registry and `dsh-remedy verify` printed `OK 6 fixture(s)`.
